# EXO Forge Studio · ATLAS R04

简体中文 · [English](README.md)

一个可在浏览器中操作的外骨骼概念设计工作台：围绕人体支撑结构、向地面传递载荷的设计目标和双机械臂，展示总装、人体动作、三指机械手及连贯任务场景。

由用户定义产品方向，**Astra** 参与建模、动作与网页交互开发。仓库包含可运行产品、可编辑工程源文件和相关验证记录。

![ATLAS 动作工作台](docs/images/atlas-workbench-en.png)

## 直接运行

启动脚本会自动准备 Node.js 和网页依赖。显示模型、骨骼、参考数据和成品视频已包含，不需要 Git LFS、Blender、后端服务或 API 密钥。

```sh
git clone --depth 1 https://github.com/VIONWILLIAMS/EXO-Forge-Studio.git
cd EXO-Forge-Studio
bash start.sh
```

Windows 克隆后运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1`。以后使用同一条启动命令即可。环境安装在项目目录，网站就绪后自动打开浏览器。全新浅克隆下载约 **144 MB**，解压后的版本文件约 **342 MB**；建议为环境、依赖和构建预留 **2 GB**。

默认入口为 [中文工作台](http://127.0.0.1:4177/?lang=zh) 或 [50 秒介绍](http://127.0.0.1:4177/?demo=intro&lang=zh)。需要在自己的电脑上保持服务终端运行；它们不是在线托管地址。4177 被占用时，脚本会换到下一个空闲端口，并打印真实地址；`--port 4180` 则要求使用指定端口。没有 Git 时，见 [压缩包安装说明](docs/INSTALL.zh-CN.md)。

推荐使用支持 WebGL2 的桌面浏览器。首次加载模型可能需要几秒。顶部「中文 / EN」切换全局语言，并记住选择；链接中的 `lang=zh`、`lang=en` 优先于记忆值。

## 当前达到哪一步

**这是数字概念展示和工程研发输入，尚未完成真实穿戴设备验证。** 向地面传递载荷是设计目标，不代表已经测得承重能力。网页没有连接硬件，设备屏数值是模拟数据。

- 步行、跑步采用公开健康受试者数据及项目适配。平均曲线不是临床标准，也不是可直接控制机器人的参数。
- 动作和道具交互通过程序编排。画面流畅、局部接触检查通过，不等于整机避碰、动力学和稳定性验证。
- 随仓库提供的 CAD 报告记录单件几何与 20 项指定接口检查；没有完成生产放行、完整装配、疲劳、真人穿戴或承重验证。
- 三指手是较新的显示模型；静态 R04 CAD 的手部尚未同步完整三指关节、驱动与生产接口。

工程细节见 [R04 研发交接](cad/v04/README.zh-CN.md)、[开发说明](docs/DEVELOPMENT.md) 和 [本次验证](docs/VERIFICATION.md)。历史报告和本次实际运行的测试分别标注。

## 开发与检查

执行 `bash start.sh --check`（Windows 在 PowerShell 启动命令末尾加 `--check`），即可自动安装、检查资源、测试和构建。如果已经能直接使用 Node/npm，原有命令也继续可用：

```sh
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 4177 --strictPort
```

测试覆盖双语文字和状态保持、动作轨迹、真实 GLB 骨骼、场景及随附 CAD 报告的数据契约。后者读取已有报告，并不会重新运行 CAD 几何检查或硬件测试。GitHub CI 会在 Linux 上执行安装、测试与构建——也就是每次提交后自动检查代码能否运行和打包。

构建仍有三维主包体积提示，模型文件单独加载。资源路径目前以网站根目录为基准；部署到仓库名子路径之前需要单独适配。公开版输出为普通静态网站 `dist/`。若本地已有 `.openai/hosting.json`，才会启用原有 Sites 托管构建流程；仓库不包含个人托管配置或登录凭据。

## 文件位置

| 路径 | 内容 |
| --- | --- |
| `src/components/` | 三维场景、总装和动作界面、模拟设备屏、视频窗口 |
| `src/domain/`、`src/state/` | 动作编排、关节/手部映射、场景与播放状态 |
| `src/i18n/` | 中英文文案和语言记忆 |
| `public/assets/v04/motion-m6/` | 当前动作模型和三指静态显示模型 |
| `public/assets/v04/environment-m6/` | 箱体、楼梯、苹果树、篮子与果实 |
| `public/assets/v04/video-m8/` | 成品 MP4 |
| `assets/source/` | 可编辑 Blender 母版，包含历史版本 |
| `cad/` | CAD 源码、设计定义及 STEP/STL/3MF 工程输出 |
| `assets/vendor/`、`assets/reference/` | 第三方网格、参考数据及授权 |
| `tests/`、`tools/` | 回归测试、建模工具和几何审计脚本 |

成品资产随代码保留，普通克隆即可运行。原始录制帧、编辑器备份、缓存、凭据和个人托管元数据不进入公开仓库。`output/v04/` 只保留测试需要的两份历史几何报告。
