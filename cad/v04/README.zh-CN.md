# ATLAS R04 研发输入交接

## 能交付到哪一步？

**可作为工程师继续研发的输入；不是照图加工、采购和装配的生产放行包。**

本包的 STEP 是真实 B-Rep 实体，不是将渲染图片包装为 CAD。每种零件有独立几何、编号、位置、单位和数量。高三角面数只影响显示细腻度，不等于尺寸准确、配合正确或承载可靠。

| 交付层级 | 当前状态 | 可以做什么 |
|---|---|---|
| 外观与人因方案审查 | 可用 | 查看棱面护壳、三个设备屏、人体轮廓、脚部支撑和空间布局 |
| 机械研发输入 | 可用 | 打开总装 STEP，拆分零件，修改设计尺寸，继续建立连接约束与运动副 |
| 局部非承重几何样件 | 有条件 | 用 STL 切片验证外观、手感、空间和局部接口；需按具体打印机设置 |
| 全套配合与装配验证 | 未完成 | 已验证 20 个指定几何关系，不覆盖整机所有连接、夹点或运动姿态 |
| 生产加工放行 | 不可用 | 仍缺真实标准件选型、生产配合公差、完整紧固/安装细节和签发图纸 |
| 真人穿戴与承重试验 | 不可用 | 无 FEA、失效保护、疲劳、台架和穿戴验证；不可将塑料样件用于承重 |

## 本轮修正

1. **臀腿变形**：R03 的肩部旋转误影响髋部顶点。R04 对原始人模中的髋部区域做保护，站姿调整不再将其绕肩部旋转；提供独立人模检查视图及回归报告。
2. **内侧主控臂**：补齐骨盆安装座、上段、肘轴、下连杆、握把固定套；不再将握把独立悬在人体旁。连接连续性不是完整的加工连接设计。
3. **前掌铰链**：使用 Ø8 实心销轴与 Ø8.4 原型轴孔，左右前/后铰链耳交错，独立端部限位。0.4 mm 是本轮样件设计间隙，不是针对某种材料/打印机验证过的公差。
4. **夹爪**：两根夹指改为同向平行，内扣指尖与摩擦垫相接。夹爪驱动和实际开合运动副仍待设计。
5. **显示系统**：胸屏 120×64、前臂屏 64×38、背部维护屏 110×42 mm；底壳、边框、盖板分别建模。网页待机/辅助/维护模式与电源开关仅改变模拟显示内容，未连接硬件。
6. **外观细节**：棱面分件护壳、内嵌深色维护板、薄型状态灯、实际表面定位的标识、贴体服装接缝、独立衣领与连续手部表面。

## 工程师首先核对的文件

- `EXO_ATLAS_R04_ASSEMBLY.step`：总装；单位 mm、Z 向上、-Y 向前。
- `step/`、`stl/`：仅本版清单中的有效零件，1:1 毫米。
- `assembly.json`：零件、数量、局部到总装刚性变换矩阵。
- `BOM.csv`：设计零件表；“机加工候选”“轴承包络”不是已完成的采购选型。
- `drawings/`：关键零件中面 DXF 与正投影 SVG，不是完整尺寸、公差和表面处理的生产工程图。
- `validation.json`：单件实体与 STL 几何校验。
- `interface-validation.json`：20 个指定位置的实体相交/间距/方向检查。
- `anatomy-validation.json`：人模髋部保护回归。
- `cad-display-alignment.json`：CAD 到网页的装配变换校验，不是人体间隙或强度证明。

`design.json` 为当前设计基准和输出说明；本版不是可随意改该 JSON 就自动解出全身约束的参数化求解器。几何尺寸应在 CAD 源函数中修改后重建，并重新检查相邻连接。

## 下一阶段的真正工程工作

按足部 → 腿部 → 躯干 → 外臂顺序，完成每个连接面的螺钉、止口、轴肩、轴承座与锁止方式；以真实电机、减速器、轴承及电池替代包络件。然后建立关节约束与全动作干涉检查、尺寸链、受力和人因验证，才能形成生产放行图纸。

## 重建

源码保留项目内的相对目录，不依赖本机绝对路径。测试环境 Python 3.11、CadQuery 2.6.1、NumPy 2.4.6、trimesh 4.11.4；Blender 5.0.1 用于人模与显示母版。

```sh
python -m pip install -r cad/requirements-cad.txt
python cad/v04/build_engineering.py
python cad/v04/check_interfaces.py
blender -b --python tools/blender/build_atlas_r04.py
node tools/validate_atlas.mjs --r04
python cad/v04/engineering_package.py
```

R03 原版保留在外置工程的 `cad/v03`、`assets/source/v03` 和 `output/v03`，便于对照；本版不会覆盖旧交付包。
