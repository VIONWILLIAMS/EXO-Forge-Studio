# ATLAS R03 — 人体外骨骼与双机械臂

本版以 1750 mm 解剖比例人模建立 1:1 设计总装。主承力链沿背部、骨盆、腿外侧及鞋底连接；辅助支撑收纳于背后。灰银曲面护壳与石墨色承力结构分层，酸橙绿用于设备识别和可拆外壳嵌件。

## 工程师从哪里开始

1. 用 `EXO_ATLAS_R03_ASSEMBLY.step` 打开总装，核对人体包络、关节中心和零件相对位置。
2. 按 `BOM.csv` 与 `assembly.json` 查找零件编号、数量、尺寸和局部到总装的变换矩阵。单位为毫米，Z 向上，-Y 向前。
3. 用 `step/` 内的独立 B-Rep 继续建模；`drawings/` 的 DXF 是零件中面二维轮廓，SVG 是正投影审查图。DXF 不是已经补齐公差的生产工程图。
4. 先核对足部：L05 踝叉 → L06 足跟/足弓承力板 → 前掌横轴 → 分段前掌板。鞋跟杯与防滑垫是单独零件。
5. 曲面护壳与嵌件共用同一母曲面，嵌件周边留 1 mm 设计缝；护壳名义厚度 3 mm。

## 核心尺寸

| 模块 | 名义尺寸 | 连接意图 |
|---|---|---|
| 肩胛桥 | 640 mm 跨度，14 mm 厚 | 双侧机械臂 → 双背轨 |
| 背部导轨 | 370 mm 长，124 mm 中心距 | 肩胛桥 → 骨盆鞍 |
| 骨盆承力鞍 | 456 × 310 mm | 前开口，连接双髋支座 |
| 髋/膝/踝轴心 | 947 / 478 / 112 mm 离地 | 以人模姿态作为初始装配基准 |
| 单脚支撑 | 286 × 124 mm，6 mm 足板 | 随鞋跟与足弓，前掌分段 |
| 踝叉 | Ø12 轴孔，2 × Ø5.5 安装孔 | 踝轴与鞋侧支承接口 |
| 工具法兰 | Ø50 孔距，4 × Ø5.5 | 可换工具与末端夹持器 |

尺寸为设计初值，不是对任意穿戴者都适用的适配结论。左右件总装变换独立，几何共形件允许复用相同 STEP 定义。

## 建議装配顺序

1. **足部子装配**：足跟板/前掌板、横轴/铰座、踝叉、后跟杯、防滑垫。先检查足部运动及所有安装面的接触关系。
2. **腿部子装配**：踝总成、小腿管、膝总成、大腿管、髋总成，再安装承托连接耳和开放承托环。
3. **躯干部子装配**：骨盆鞍、双导轨、滑块、肩胛桥；在人模上检查背部间隙与穿脱开口。
4. **机械臂子装配**：偏航基座、叉架、肩驱动壳、上臂、肘部、前臂滚转、腕部、工具法兰及夹爪。
5. **服务件**：电源匣、控制器、快接头、走线和服务环。
6. **外观件**：曲面壳、同曲面嵌件、分节背甲和织物承托层。壳体固定耳与全部生产紧固接口仍需后续详细设计。

## 可打印范围

STL 与 STEP 同源，全部按 1:1 毫米导出。它们可用于切片及非承重几何样件；例如足跟板、前掌板、踝叉和外壳配合样件。大件需根据实际打印机分件，未提供通用 G-code，也未实际打印。金属承力件不能因为导出了 STL 就替换成塑料承重。

## 已建模与待完成

已建模：零件外形、壁厚、孔位、通风切口、法兰孔阵列、轴承安装腔、外壳分件、足部铰接包络、紧固件占位与可见走线。

待完成：全部接触/安装关系的约束求解，完整多轴运动学，壳体安装耳，生产配合公差，轴承、电机、减速器与电池选型，载荷和疲劳计算，电气布线图，台架试验和实物穿戴。因此本版是供工程师推进设计的详细数字总装，不是已签发的生产图纸。

## 重建与检查

```sh
.venv-cad/bin/python cad/v03/build_engineering.py
.venv-cad/bin/python cad/v03/engineering_package.py
/opt/homebrew/bin/blender -b --python tools/blender/build_atlas.py
node tools/validate_atlas.mjs
```

CAD 有效性见 `output/validation.json`；网页显示分组与 CAD 包络一致性见项目根 `output/v03/cad-display-alignment.json`。后者用于检查左右装配变换是否在网页导出时被破坏。
